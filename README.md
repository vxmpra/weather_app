# WEATHER APP

**Интерактивное приложение для отображения погоды и карты по координатам**

**Автор:** Колмыкова Александра
---
# Описание проекта

Weather App — это веб-приложение, позволяющее пользователю получать подробную информацию о погоде по введённым координатам. Проект выполнен без использования сторонних библиотек и фреймворков. Интерфейс позволяет пользователю добавлять на экран несколько независимых виджетов с погодой. Любой виджет можно удалить в любой момент. Это даёт возможность одновременно отслеживать погоду в нескольких локациях без переключения между экранами.

Приложение интегрируется с двумя внешними API: OpenWeatherMap для получения погодных данных и Яндекс.Картами для отображения местоположения на карте. Каждый виджет включает в себя актуальные данные о погоде, локальное время в выбранной точке, а также карту с точкой расположения. 
---
# Функциональные возможности

**1. Валидация координат:** Проверка широты (-90 до 90) и долготы (-180 до 180).

**2. Асинхронные запросы:** Получение данных через OpenWeatherMap API с использованием fetch и async/await.

**3. Динамические виджеты:** Создание независимых виджетов погоды для каждой локации с отображением:
   * Основные параметры (температура, влажность, ветер, давление, видимость)
   * Локальное время (автоматический расчёт часового пояса)
   * Иконки погоды (адаптивные изображения под разные условия: солнце, облака, дождь, снег и тд)
   * Карта Яндекс.Карт с меткой координат
     
**4. Управление виджетами:** Возможность удаления любого виджета без перезагрузки страницы. Поддержка неограниченного количества виджетов.
     
**5. Интеграция с картами:** Отображение местоположения на интерактивной карте Яндекс.Карт для каждой локации с маркером.
