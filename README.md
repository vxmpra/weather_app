🌦️**WEATHER APP**🌦️
**интерактивное приложение для отображения погоды и карты по координатам**

**Описание проекта**

Weather App — это интерактивное веб-приложение, позволяющее пользователю получать подробную информацию о погоде по введённым координатам. Приложение полностью реализовано на нативном JavaScript без использования сторонних библиотек и фреймворков, что подчёркивает чистоту, прозрачность и структурированность кода. Интерфейс построен таким образом, чтобы пользователь мог легко добавлять и удалять независимые виджеты погоды, располагать их на странице и просматривать данные по разным локациям одновременно.

Приложение интегрируется с двумя внешними API: OpenWeatherMap для получения погодных данных и Яндекс.Картами для отображения местоположения на карте. Такая комбинация позволяет сделать работу с погодной информацией более наглядной, удобной и визуально понятной. Каждый виджет включает в себя актуальные данные о погоде, локальное время в выбранной точке, а также карту с точкой расположения. Благодаря продуманной архитектуре приложение работает быстро, корректно и стабильно даже при большом количестве виджетов.

**Функциональность**

Приложение предоставляет пользователю широкий набор возможностей. Система проверяет корректность введённых координат, гарантируя, что данные попадают в допустимый диапазон широты и долготы. После успешной проверки пользователь может создавать любое количество независимых виджетов погоды, каждый из которых отображает собственную информацию и работает полностью автономно.

Для каждой географической точки загружается подробная информация о погоде: текущая температура, описание состояния неба, ощущаемая температура, влажность, атмосферное давление, скорость ветра и видимость. Помимо этого, приложение показывает локальное время в выбранной локации, автоматически рассчитывая смещение по часовому поясу.

Каждый виджет оснащён соответствующей иконкой погоды: солнечно — ☀️, облачно — ☁️, дождь — 🌧️, снег — ❄️ и т.д., что делает интерфейс более живым и наглядным. Кроме того, под погодным блоком отображается встроенная карта Яндекс.Карт с меткой, указывающей на введённые координаты. Это позволяет мгновенно увидеть точку на карте и визуально сопоставить локацию с погодой.


Пользователь также может удалять любую карточку с погодой в один клик, не перезагружая страницу. Каждая карточка формируется динамически, что делает приложение масштабируемым и удобным для работы сразу с несколькими локациями. Такое решение позволяет анализировать погоду в разных регионах одновременно.
